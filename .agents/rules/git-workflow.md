# Regra de Git: Commits e Pushes Apenas sob Demanda Explícita

1. **Nunca Fazer Commits Automáticos:** Não execute `git commit` ou `git push` de forma autônoma após realizar edições, refatorações ou criações de arquivos.
2. **Apenas sob Solicitação Direta:** Faça commit e envie para o repositório remoto **apenas** quando o usuário pedir explicitamente através de comandos como *"manda pro git"*, *"faz o commit"*, *"comita e sobe pro github"*, ou similar.
3. **Fluxo Padrão:** Durante os ciclos de trabalho, concentre-se nas alterações e validações de arquivos locais. Deixe para salvar os commits quando o usuário der a ordem.
